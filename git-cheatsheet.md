
# Git Command Cheatsheet

A quick reference for common Git commands.

## Start a Repository

```bash
git init
```

## Check Repository Status

```bash
git status
```

## Stage Changes

```bash
git add .
```

## Commit Changes

```bash
git commit -m "Describe your changes"
```

## View Commit History

```bash
git log --oneline
```

## Create a Branch

```bash
git branch feature-name
```

## Switch Branch

```bash
git switch feature-name
```

## Push Changes

```bash
git push origin main
```

## Pull Latest Changes

```bash
git pull origin main
```

## Useful Tip

Write clear commit messages and review changes before pushing.
